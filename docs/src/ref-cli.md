## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | No findings. |
| 1 | One or more findings, of any severity. `--min-severity` does not change this. |
| 2 | Usage error. |
| 3 | Input error. BACcheck cannot read the capture. |
| 4 | Internal failure. This includes a report that cannot be written. |

# Read a finding

Use this guide to read one finding in a BACcheck report.

1. Read the severity tag. It tells you how urgent the finding is. See [Severity levels](ref-severity.md).
2. Read the "Affected" line. It names the device or devices involved.
3. Read the evidence text. It states what BACcheck saw in the capture.
4. Read the frame numbers. Open your capture tool and jump to these frames to see the raw packets. A finding shows at most five example frames. The evidence text gives the totals.
5. Read the numbered steps. They are the remediation for the finding.

For the list of all findings and their steps, see [Issue catalogue](ref-issues.md).
